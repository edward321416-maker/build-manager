# Final artifact release policy

There are **no approved final artifacts** in this directory. This policy file keeps the release boundary explicit; it is not an application or placeholder submission.

Only artifacts that pass the [final gate](../final_gate.md) and receive approval for their concrete version may be added. Record a release manifest with version, relative artifact names, SHA-256 hashes, source-draft commit, verified requirement version, reviewer, approval date, and public-release clearance. Create versioned releases rather than overwriting earlier approved artifacts.

Personal application fields, identities, signatures, contracts, and private submission receipts must be stored through an approved private channel, even if required by the application portal. This public directory may contain only cleared non-personal submission derivatives. A file here must not imply actual submission; that status requires a real receipt.
