# Evidence checklist

Status: **OPEN / DRAFT**. Check only when the stated evidence has actually been reviewed; the existence of a guide or registry is not research completion.

- [ ] Current official announcement and amendments verified with exact locators (SRC-002).
- [ ] Landlord problem evidence collected with consent and sampling limitations (CLM-003).
- [ ] Tenant problem evidence collected with consent and sampling limitations (CLM-004).
- [ ] Successful existing workflows and disconfirming cases documented.
- [ ] Domestic competitors checked against current primary pages; vendor claims distinguished from tests.
- [ ] International precedents checked with geographic and applicability limits.
- [ ] Technical feasibility assessed using synthetic cases and observed results (CLM-008).
- [ ] Legal, safety, privacy, and human-handoff boundaries reviewed with current primary sources.
- [ ] Any numerical statement has date, population, denominator, method, and limitations; otherwise remove it.
- [ ] All public summaries anonymized; raw originals remain private and unmodified.
- [ ] External text/media reuse rights confirmed; links used where redistribution is not authorized.

Evidence records must identify reviewer, date, source/claim IDs, and the relevant note. Missing evidence remains `[TO VERIFY]`; do not tick a box from a prior summary or filename alone.
