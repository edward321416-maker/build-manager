# 디자인 규칙 적용 현황

이 문서는 규칙집이 아니라 기록입니다. 규칙은 [디자인 규칙](DESIGN_RULES.md)에 있습니다.

- [DECISION] 2026-10-13 운영자 결정: 디자인 규칙 파일이 크기 한도(48,000바이트)에 닿아, 규칙이 아닌 기록인 16절의 목록과 18절의 기록 표를 이 문서로 옮겼습니다. 규칙은 그대로이고, 옮긴 글은 이 문서에 맞게 '디자인 규칙' 같은 말만 더했습니다.
- 디자인 작업 전에는 디자인 규칙 전체와 함께 이 문서의 '아직 규칙을 따르지 않는 화면'도 확인합니다.

## 아직 규칙을 따르지 않는 화면

디자인 규칙 [16절](DESIGN_RULES.md#16-아직-규칙을-따르지-않는-화면)의 목록입니다. 첫 화면 `/`, `/core`, `/vendor/job`은 2026-10-10에 규칙으로 옮겼습니다. 다음 디자인 작업에서 아래를 옮깁니다.

- 예전 데모 화면 `/demo/*`(체험 모드 전용, 실제 사이트에서는 404)
  - 규칙으로 옮기지 않고, 앱 v2 때 체험 모드 전체와 함께 지웁니다(디자인 규칙 맨 위 2026-10-10 결정).
  - 남은 차이는 `apps/web/src/app/globals.css`의 초록·베이지 색입니다.
  - `apps/web/src/components/tenant`의 `TicketIntake`와 `apps/web/src/components/landlord`의 `TicketReview`는 `/core`도 쓰므로 그때도 남깁니다.
  - `/demo/layout.tsx`는 B1 인수 기록(FROZEN)에 있어서, 지울 때는 고위험 절차를 따릅니다.
- 내비게이션
  - 웹 `/core`는 2026-10-13에 하단 탭바와 왼쪽 메뉴로 옮겼습니다(P5). 아이콘은 Tabler 3.49.0에서 쓰는 것만 가져왔습니다(패키지 없음, SPDX 표시).
  - 남은 것: 앱 탭바(앱 v2), `/workspace`(옛 디자인), 도움말·문의·약관·알림 설정 행(내용이 생긴 뒤).
- 모바일 앱
  - 색과 글자 스타일 값은 `apps/mobile/src/design/tokens.ts`에만 두고, `tokens.test.ts`가 다른 파일의 직접 지정을 막습니다.
  - 남은 것
    - 하단 탭바(위 내비게이션 항목)와 안전 영역 처리
    - 앱 문구: 합쇼체, 영문 'DEMO MODE'·'BUILDING-AWARE REPAIR ROUTER' 표시
    - 접수 흐름의 입력칸 세 개(개발 접근 코드, 처리 기록, 문제 설명)에는 보이는 라벨 없이 안내 글자만 있습니다([8.2](DESIGN_RULES.md#82-입력칸)).
    - 선택 타일의 두 칸 배치와 이름·설명 두 줄([8.3](DESIGN_RULES.md#83-선택-타일))
    - 누름 상태(`primary-hover`, 98%)와 움직임 토큰
    - `apps/mobile/app.json`의 `userInterfaceStyle`이 `automatic`이라, 휴대폰이 다크 모드면 상태 막대·키보드 같은 시스템 부분만 어두워집니다(디자인 규칙 2절은 밝은 화면만).
- 합쇼체("~습니다") 문구
  - `/core`와 `/vendor/job`(넣은 컴포넌트 포함)은 2026-10-13에 해요체로 옮겼습니다(P3 묶음 3).
  - 남은 것: 서버가 보내 화면에 그대로 보이는 오류 문장(`apps/web/src/server`), `/workspace` 화면(B1·B3), 모바일 앱 화면(앱 v2에서 웹과 같은 문구로 맞춤. 앱의 결정 화면은 아직 '추천 경로'. 웹과 함께 쓰는 API 클라이언트의 오류 문장만 이미 해요체), 체험 전용 문구(`/demo/*`, 위 결정대로 앱 v2 때 지움). `/demo`는 `/core`와 함께 쓰는 컴포넌트만 해요체라 두 말투가 섞여 보입니다.
  - 시험(`apps/web/src/app/core/haeyo-copy.test.ts`)이 위 화면과 컴포넌트에 합쇼체 문장이 다시 들어오지 않는지 봅니다.
- `/core`에 남은 것
  - 사진 썸네일, 보조 정보의 `caption` 스타일, 1024px 이상 왼쪽 메뉴 너비 248px, 호실 정비 이력의 목록 행은 2026-10-12에 옮겼습니다(PR #122). 768~1023px의 왼쪽 메뉴도 2026-10-13에 옮겼습니다.

## 운영자 지적 기록

디자인 규칙 [18절](DESIGN_RULES.md#18-운영자-지적-기록)의 순서대로 처리한 지적의 기록입니다. 새 지적은 이 표 아래에 한 줄씩 더합니다.

| 2026-10-10 | 버튼이 아래 구분선에 붙음 | 마지막 버튼의 아래 여백이 적용되지 않음 | [4절](DESIGN_RULES.md#4-간격) 상자 안 여백, 구역 사이 30px | 화면 캡처 확인 |
