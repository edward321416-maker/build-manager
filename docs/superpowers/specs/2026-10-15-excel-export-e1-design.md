## 설계

화면이 이미 서버에서 받은 목록으로 브라우저가 CSV 파일을 만든다. 새 API, 마이그레이션, 서버 코드는 없다.

### 받는 범위

| 화면 | 받는 행 | 순서 |
| --- | --- | --- |
| 업무함(`ManagerWorkQueue`) | 지금 고른 호실·상태·긴급도 필터에 보이는 요청 전부(`visible`). 서버 함수 `core_flow.list_manager_work`는 건수 제한이 없어 화면이 가진 목록이 접근 가능한 전체다. | 화면과 같은 순서(`compareManagerWork`) |
| 호실 정비 이력(`ManagerMaintenanceTimeline`) | 고른 호실 하나의 정비 사실, 화면과 같은 최근 100건까지(`CoreUnitMaintenanceFactsSchema`의 `max(100)`) | 화면과 같은 순서(서버가 준 순서) |

- 접근 권한은 지금과 같다. 업무함 목록은 서버가 `ORG_ADMIN`·`PROPERTY_STAFF`와 `can_unit`으로 거른 뒤에 준다. 파일에는 화면에 이미 보이는 값만 들어간다.
- 넣지 않는 것: 세입자 이름·연락처, 세입자가 쓴 설명 글, 사진, 내부 메모, 대화 내용, 접수 단계(intake) 상태, 업체 정보.

| 비고 | 늘 빈 칸 |

- 순서는 판매처가 설명한 국내 수리·하자 대장처럼 날짜부터 시작하고(CLM-202, CLM-203, CLM-205), 점포수리 관리대장 설명처럼 비고 칸으로 끝난다(CLM-203). 비고 칸의 근거는 그 설명 한 곳뿐이고, 공통 모양은 가설이다(CLM-211). 행의 순서는 위 "받는 범위"대로 화면 순서이고, 날짜순으로 보고 싶으면 엑셀에서 첫 칸으로 정렬한다.
- 엑셀 필터는 날짜 칸을 연·월·일로 고를 수 있어(CLM-210) '월' 칸은 따로 두지 않는다. 날짜 칸이 엑셀에서 날짜로 인식되는지는 엑셀 실물 확인에서 본다.
- 비고 칸에 적은 메모는 다시 받으면 새 파일이라 옮겨지지 않는다. 비용·업체 칸은 우리 기록에 값이 없어 넣지 않고, 비용 기록 기능을 만들 때 다시 본다.

- 상태·조치·응답 이름은 화면이 쓰는 표를 그대로 import한다. 파일에서 이름을 새로 짓지 않는다(디자인 규칙 8.7).
- 시각은 한국 시간 `YYYY-MM-DD HH:MM`(초 버림)이다. 브라우저 시간대와 관계없이 `instantToSeoulLocal`(`apps/web/src/lib/date-text.ts`)로 만든다.
- 파일 이름의 날짜는 받은 날의 한국 날짜다. 건물·호실 이름 속 `\ / : * ? " < > |`와 제어 문자는 `_`로 바꾸고, 공백은 지운다(시안 `정비이력_해솔빌라_101동1203호_2026-10-15.csv`).

### 파일 모양

- UTF-8에 BOM(`EF BB BF`)을 붙인다. 한국어 Windows의 엑셀이 BOM 없는 UTF-8 CSV를 다른 인코딩으로 읽어 글자가 깨지는 것을 막는다.
- 구분자는 쉼표, 줄 끝은 CRLF, 첫 줄은 헤더다(RFC 4180).
- 모든 칸을 큰따옴표로 감싸고, 칸 안의 큰따옴표는 두 번 쓴다(OWASP CSV Injection).
- 수식 막기: 칸 값이 `=`, `+`, `-`, `@`, 탭(0x09), CR(0x0D), LF(0x0A), 또는 전각 `＝`, `＋`, `－`, `＠`로 시작하면 앞에 작은따옴표 `'`를 붙인다(OWASP CSV Injection의 표준 처리). 모든 칸을 감싸고 큰따옴표를 두 번 쓰므로, 구분자나 따옴표로 위험 문자를 새 칸의 맨 앞에 옮기는 우회도 막힌다.
- 날짜·요청 번호는 숫자나 위 문자로 시작하지 않으므로 막기 처리에 걸리지 않고, 엑셀이 날짜 칸을 날짜로 알아본다.

### 화면

- 버튼: 보조 버튼(디자인 규칙 8.1), 글자 "엑셀로 받기".
  - 업무함: 제목 줄(`.title`) 오른쪽. 오류 때 나오는 "업무함 다시 불러오기"가 있으면 그 오른쪽에 둔다. 줄이 좁으면 지금 CSS(`flex-wrap`)대로 다음 줄로 내려간다.
  - 호실 정비 이력: 제목 줄(`.heading`)의 "이력 다시 불러오기" 오른쪽. 767px 이하에서는 지금도 제목 아래로 내려간다(`.heading{display:block}`). 768px 이상에서는 줄바꿈이 없어 왼쪽 메뉴 옆 좁은 내용 폭과 글자 200%에서 버튼 두 개가 제목을 누를 수 있으므로, 업무함 제목 줄처럼 `flex-wrap: wrap`을 더한다.
- 누를 수 없을 때: 불러오는 중, 불러오기 오류, 보이는 행이 0건, 화면 전체가 바쁠 때(`disabled`). 이유는 이미 목록 자리에 보이는 빈 화면·오류·불러오는 중 안내가 알려 준다.
- 누르면 파일을 만들어 바로 내려받게 하고(`Blob` + `URL.createObjectURL` + `<a download>`; 끝나면 `revokeObjectURL`), 토스트로 알린다.
  - 업무함: "업무함 {N}건을 엑셀 파일(CSV)로 받았어요."
  - 호실 정비 이력: "정비 이력 {N}건을 엑셀 파일(CSV)로 받았어요."
- 토스트(디자인 규칙 8.9): 지금 웹에는 토스트가 없어 작은 공용 컴포넌트를 하나 만든다. 화면 아래 가운데, 하단 탭바가 있는 폭(767px 이하)에서는 탭바 위 10px, 바탕 `text`, 글자 `text-inverse` `label`, 모서리 10px, 최대 너비 32rem, 그림자 `--shadow-float`, 층 40, 3초 뒤 사라짐, `role="status"`. 움직임은 `motion-base`이고 `prefers-reduced-motion`이면 끈다.
- 파일을 만들다 실패하면(브라우저가 막는 경우 등) 토스트가 아니라 그 자리 안내 상자로 "파일을 만들지 못했어요. 다시 받아 주세요."를 보인다(8.9, 8.11).

## 위협·남용 사례

| 사례 | 어떻게 | 막는 방법 |
| --- | --- | --- |
| 수식 주입 | 관리자나 다른 사용자가 담당자·부품·위치·건물·호실 이름에 `=HYPERLINK(...)`, `@SUM(...)`, `-2+3` 같은 값을 넣고, 다른 관리자가 받은 파일을 엑셀로 열면 수식이 돈다 | 위 "수식 막기" 처리와 모든 칸 감싸기. 시험으로 고정한다 |
| 권한 밖 자료 유출 | 파일 기능으로 볼 수 없는 호실·요청을 받으려 함 | 새 API가 없다. 파일은 서버가 이미 권한으로 거른 화면 목록에서만 만든다. 권한 시험은 지금 서버 시험이 그대로 지킨다 |
| 개인정보가 PC에 남음 | 받은 파일이 공용 PC의 다운로드 폴더에 남거나 메일로 퍼짐 | 세입자 이름·연락처·설명 글·사진·내부 메모를 넣지 않는다. 남는 것은 건물·호실·상태·날짜·담당자 표시 이름이다 |
| 다운로드 점검 기록 없음 | 실데이터에서 누가 언제 받았는지 알 수 없음 | 지금은 합성 데이터 데모뿐이다. 세입자 정보를 넣거나 실서비스로 가기 전에 서버 쪽 다운로드 기록을 따로 설계한다(개인정보의 안전성 확보조치 기준 제8조 제2항, CLM-160) |
| 파일 이름 조작 | 건물 이름에 `../`나 `:` 같은 글자를 넣어 저장 위치나 이름을 비틂 | 브라우저는 `download` 이름의 경로를 따르지 않는다. 그래도 위험 글자는 `_`로 바꾼다 |
| 낡은 자료 | 마지막으로 불러온 뒤 바뀐 내용이 파일에 빠짐 | 파일은 화면에 보이는 그대로이고, 건수를 토스트로 알린다. 받기 전에 새로고침하는 것은 사용자 몫이다(남은 위험) |

## 시험

실패하는 시험부터 쓰고, 목표 동작이 실제로 실패하는 것을 본 뒤 구현한다(DEV-04).

- 단위(`apps/web/src/lib/csv-file.test.ts`): BOM과 CRLF, 큰따옴표 두 번 쓰기, 쉼표·줄바꿈이 든 칸, 위험 시작 문자 11개 각각, 위험 문자가 가운데에만 있는 값은 그대로, 빈 값, 파일 이름 다듬기.
- 단위(`apps/web/src/app/core/export-rows.test.ts`): 두 종류의 헤더 순서(날짜가 첫 칸, 비고가 끝 칸이고 늘 빈 칸), 이름 표 사용, 빈 칸, 시각이 브라우저 시간대(예: `America/Los_Angeles`)와 관계없이 한국 시간인지.

## 롤백

- 화면 코드만 바뀌므로 이 PR을 되돌리는 커밋 하나로 끝난다. 데이터·마이그레이션 롤백은 없다.
- 데모에 배포한 뒤 문제가 생기면 [VM 배포 절차의 Rollback](../../../deploy/vm/README.md#rollback)대로 직전 이미지 아카이브로 되돌린다. 두 이미지 사이에 마이그레이션이 없다.

## 남은 위험

- 엑셀이 일부 호실 이름(예: `3-4`)을 날짜로 바꿔 보일 수 있다. 화면이 기준이고, 파일은 보기용이다.
- 작은따옴표를 붙인 칸은 엑셀에서 `'`가 글자로 보인다. 그런 값은 드물다.
- OWASP는 모든 표 프로그램에 맞는 처리 방법은 없다고 적는다. 엑셀 기준으로 시험한다.
- 다운로드 기록과 세입자 정보 넣기는 이 설계 밖이다(위 위협 표).
