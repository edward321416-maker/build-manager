# 내비게이션·아이콘 규칙 설계

- 날짜: 2026-10-10 (Asia/Seoul). 작성: Claude Opus 5.5 (Claude Code, AI 작성). 사람 검토: 운영자가 설계 요약을 승인(2026-10-10), 문서 검토는 PR에서.
- 결과물: [디자인 규칙](../../../design/DESIGN_RULES.md)의 내비게이션 규칙 추가. 이 문서는 결정의 근거와 대안을 남긴다.
- 근거 연구: `research/ux/2026-10-10-ia-feature-audit-reference.md` ([PR #87](https://github.com/edward321416-maker/build-manager/pull/87)). 기준표 C-01–C-09, 관찰 O-01·O-04·O-13을 이 규칙이 다룬다.

## 1. 배경

- 연구에서 확인한 것
  - 모바일 앱에는 탭바가 없다.
  - 웹 `/core`의 1차 메뉴는 두 칸뿐이다.
  - 넓은 화면 왼쪽 메뉴에서는 로그아웃이 메뉴 항목보다 위에 있다.
  - 디자인 규칙 v1에는 하단 탭바 사양과 아이콘 세트가 없다.
- 공식 가이드라인이 권하는 것
  - 모바일 1차 메뉴는 하단 탭 3~5개로 둔다(Apple HIG, Android, KRDS).
  - 탭에는 아이콘과 짧은 라벨을 함께 쓴다.
  - 선택 상태를 분명히 표시한다.
  - 숨기지 않는 메뉴를 쓴다.
- 운영자 결정(2026-10-10)
  - 모바일 앱이 주 타겟이다.
  - 탭바와 아이콘 규칙을 만든다.
  - 아이콘 세트는 Tabler로 한다.
  - 선택된 탭은 채운 아이콘·파랑·굵은 라벨로 표시한다.
  - 휴대폰 폭 웹도 앱과 같은 탭바를 쓴다.
  - 위 내용을 담은 설계 요약을 승인했다.
  - 태블릿 폭(768–1023px) 웹은 왼쪽 메뉴를 쓴다(PR 검토 중 추가 결정).

## 4. 수치

규칙 본문이 기준이다. 이 표는 설계 확인용 요약이다.

| 항목 | 값 |
| --- | --- |
| 탭바 높이 | 56 + 아래 안전 영역. 상단 바와 같은 높이 |
| 탭 수 | 3~5. 넘치면 맨 오른쪽 '더 보기' |
| 칸 안 | 위 5 → 아이콘 24 → 5 → 라벨 `tab`(13/17) → 아래 5 = 56. 아래 안전 영역은 그 아래에 더함 |
| 색 | 바탕 `surface`, 위쪽 선 `border` 1px. 기본 `text-secondary`(흰 바탕 5.7:1), 선택 `primary`(흰 바탕 약 4.9:1) |
| 라벨 | 한두 단어, 공백 포함 4자 이내, 한 줄. 320px에서 5칸이면 칸 너비 64px |
| 배지 | 높이 18, 최소 너비 18, 좌우 5, 모서리 5, 바탕 `badge` `#C8231A`(흰 글자 약 5.7:1), 글자 `tab` 600, 99건 초과는 '99+' |
| 아이콘 | Tabler 선 1.5(24 기준), 채운 모양은 탭바·왼쪽 메뉴의 현재 위치에만 |
| 왼쪽 메뉴 | 248px, 항목 높이 50·좌우 15, 아이콘 20 → 5 → 라벨 `body`, 현재 위치는 채운 아이콘·600·`fill-hover`. '더 보기' 항목은 펼쳐 두고, 맨 아래 계정 영역('내 정보') |
| 토스트 | 하단 고정 버튼이나 하단 탭바 위 10px |

대비 값은 WCAG 상대 휘도 공식으로 계산했다: `#0064FF` 대 흰색은 약 4.9:1(4.92), 흰색 대 `#C8231A`는 약 5.7:1(5.66)이다.

## 5. 검토한 대안

### 5.1 아이콘 세트 (REF-06 확인, 2026-10-10)

| 세트 | 라이선스 | 최근 배포 | 유지 관리 | 주간 내려받기(React) | 선 기본값 | 채운 모양 | 앱 패키지 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Tabler (선택) | MIT | 3.49.0, 2026-10-05 | 기여자 100명 이상, npm 관리자 2명 | 약 358만 | 2 (1.5로 조정) | 1,054/5,184 | `@tabler/icons-react-native` 3.49.0(`react-native-svg` 필요) |
| Phosphor (추천했던 안) | MIT | 웹 React 2.1.10, 2025-05-22 / 앱 3.0.6, 2026-04-23 | 웹 패키지 배포가 12개월을 넘음 | 약 511만 | 약 1.5(regular) | 전부 | `phosphor-react-native`(커뮤니티) |
| Iconoir | MIT | 7.12.1, 2026-08-12 | 기여자 22명 | 약 15만 | 1.5 | 확인한 6개 중 0개 | `iconoir-react-native`(주간 약 1.4만) |
| Lucide | ISC | 1.54.0, 2026-10-09 | 기여자 100명 이상 | 약 1억 824만 | 2 | 없음 | `lucide-react-native` |

- 숫자는 npm 레지스트리·npm 내려받기 API·GitHub API에서 읽었다. 내려받기 수는 채택도의 참고일 뿐 품질 근거가 아니다.
- 채운 모양 개수는 jsDelivr의 `@tabler/icons@3.49.0` 파일 목록(`icons/outline`, `icons/filled`)에서 셌다.
- Lucide는 채운 모양이 없다. AI가 만든 화면에서 흔한 기본값이라 디자인 규칙 11절(AI 티)과도 맞지 않아 제외를 권했다.

### 5.2 선택 표시

| 안 | 장점 | 단점 |
| --- | --- | --- |
| 채운 아이콘 + 파랑 + 굵게 (선택) | KRDS 지침과 같고 상태가 세 가지로 드러난다 | 탭 아이콘이 짝 있는 것으로 제한된다 |
| 선 아이콘 그대로 + 파랑 + 굵게 | 모든 아이콘을 쓸 수 있다 | 선택 상태가 약하게 보인다 |

### 5.3 탭바 높이

56을 골랐다. 상단 바(5절)와 같은 높이이고, 아이콘 24·간격 5·라벨 18이 들어간 뒤 위아래 여백이 남는다. 글자를 키우면 높이가 함께 늘어난다.

## 6. 후속 작업

이 PR은 규칙만 바꾼다. 아래 순서로 따로 진행한다.

1. **웹 의존성**: `@tabler/icons-react`를 정확한 버전으로 고정해 추가한다. REF-06 평가와 `npm audit --omit=dev` 결과를 PR에 적는다([개발 규칙](../../../development/DEVELOPMENT_RULES.md) DEV-10).
2. **앱 의존성**: `react-native-svg`와 `@tabler/icons-react-native`를 `npx expo install`로 추가한다.
   - `react-native-svg`는 네이티브 모듈이라 앱 빌드를 다시 만들어야 할 수 있다. [TO VERIFY] Expo SDK 57 문서로 확인한다.
3. **탭바 구현**: 웹·앱 공통 탭바와 계정 메뉴를 만들고, 디자인 규칙 16절에 적은 화면을 옮긴다.
4. **탭 구성 확정**: 역할별 탭 구성은 메뉴 점검(연구 노트 10.1)에서 정한다.
5. **라이선스 고지**: 오픈소스 라이선스 고지 화면을 만든다.
