# 참고 사이트 배치 복제 허용 — 실제 프로젝트 비교

날짜: 2026-10-13 (Asia/Seoul). 기준: main `b1a4aa6`. 작성: Claude Code 세션. 성격: [레퍼런스 규칙](../../../references/REFERENCE_RULES.md) REF-02의 규칙 변경 전 비교 기록이며 법률 자문이 아니다.

## 왜 했나

- [DECISION] 2026-10-13 운영자: "통째로 복제하는 규칙 없애줘". 첫 화면(`/`)이 좌우 빈 공간이 많고 단순하다고 지적한 뒤, 참고 사이트를 고르던 중이었다. 참고 사이트로는 채널톡(channel.io/kr)을 골랐다.
- [DECISION] 2026-10-13 운영자: 고른 사이트의 배치가 디자인 규칙의 정렬·버튼 개수·카드 배치 규칙과 부딪히면 참고 사이트 배치를 따른다("채널톡 배치 우선").
- [DECISION] 2026-10-13 운영자: 부정경쟁방지법 위험(널리 알려진 서비스와 헷갈릴 만큼 따라 하기)을 알고 진행한다("알고 진행").
- [DECISION] 2026-10-13 운영자: 이번 변경도 REF-02의 실제 프로젝트 비교를 한다("비교하고 진행").

## 가져오지 않은 것과 이유

- B1의 "generic header" 같은 구체 절차: 영국 정부 서비스용이라 우리와 맞지 않는다.
- B3의 법무 위원회: 1인 운영이라 운영자에게 묻는 것으로 대신한다(이미 있는 규칙).
- B2처럼 우리 디자인 자산의 사용 조건을 정하는 일: 이번 변경 범위 밖이다.

## 우리에 맞게 바꾼 것

- 외부 문서들은 "남이 우리를 가져다 쓸 때"나 "코드를 들여올 때"를 정한다. 우리 규칙은 "우리가 남의 화면 배치를 가져올 때"를 정하므로, C2·C3을 가져오는 쪽의 의무로 바꿔 적었다.
- 디자인 규칙과 부딪힐 때의 우선순위는 운영자 결정대로 적었다. 참고 사이트 배치가 정렬·버튼 개수·카드 배치 규칙보다 앞서고, 사실이 아닌 내용(가짜 숫자·후기·로고), 사진, 접근성, 문구, 토큰 값은 디자인 규칙을 따른다.
